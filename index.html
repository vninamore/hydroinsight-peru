SYSTEM DESIGN

One question, five languages

Each technology has a specific role instead of being added for decoration.

01

Python

Deterministic data generation, conceptual water balance, routing and automated tests.

python/generate_data.py
02

PostGIS

Spatial schema, quality constraints, geometry indexes and operational alert queries.

sql/schema.sql
03

R

Gumbel extreme-value analysis and discharge estimates for return periods.

r/extreme_value_analysis.R
04

Julia

Fast reservoir rule-curve simulation with reliability and spill indicators.

julia/reservoir_simulation.jl
05

JavaScript

Accessible, dependency-free exploration of scenarios, maps and hydrographs.

web/app.js

MODEL TRANSPARENCY

Designed to be inspected, challenged and extended.

DATA

Synthetic, not disguised

The bundled series are deterministic demonstration data. The model is ready for adapters to SENAMHI, NASA POWER or ERA5.

QUALITY

Validation by design

Database constraints, quality flags, duplicate checks and unit tests make assumptions explicit and auditable.

LIMITS

Decision support, not forecasting

This conceptual model is a portfolio demonstration and must be calibrated before any operational hydrological use.
